# 04.14 服务端引擎 `evolve_server/engines/`

> 两个引擎实现 + 公共 mixin + OpenClaw 子进程管理 + agent workspace 抽象。

## 设计动机

`pipeline/` 是纯业务步骤(无 IO),`engines/` 是"如何调度 pipeline"的 orchestrator。`engines/` 持有:

- **bucket handle**(对象存储的连接)
- **LLM client**(异步 LLM)
- **registry**(skill ID / version)
- **config**(EvolveServerConfig)

并对外暴露 `run_once()` / `run_periodic()` / `create_http_app()` 三个方法。

`engines/` 下还有 `openclaw_runner.py` 和 `agent_workspace.py`,给 `agent` 引擎专用。

## 核心概念

| 概念 | 定义 | 引用 |
|---|---|---|
| **Evolve Server** | 独立 Python 进程,周期读 session、调 LLM、生成 skill、写回共享存储;**不**跟 client 走 RPC,只通过共享对象存储通讯 | 02 / 03.04 / 03.05 |
| `EvolveEngineMixin` | 公共 mixin(bucket 构建、远程 skill 拉取、冲突检测、storage sync→async 包装) | `engines/common.py` |
| `EvolveServer` | **workflow 引擎**实现:3 阶段 LLM 流水线(Summarize / Aggregate / Execute) | `engines/workflow.py:52` |
| `AgentEvolveServer` | **agent 引擎**实现:启动 OpenClaw 子进程用工具编辑 skill(opt-in) | `engines/agent.py:133` |
| `OpenClawRunner` | OpenClaw 子进程封装(asyncio.create_subprocess_exec) | `engines/openclaw_runner.py:24` |
| `AgentWorkspace` | agent 的工作目录(workspace 抽象,默认 `evolve_server/agent_workspace/`) | `engines/agent_workspace.py` |
| `load_agents_md` | 加载 `EVOLVE_AGENTS.md`(agent 引擎的 system prompt 文档) | `engines/agents_md.py` |
| `_AnthropicMessagesLLMClient` | agent 引擎自带的 Anthropic 客户端(httpx 直发 /v1/messages) | `engines/agent.py:47` |
| `_call_storage` | 把同步的 storage 函数(boto3 / oss2 / Nacos client)包成 awaitable 用 `loop.run_in_executor` | `engines/common.py` |
| `_build_server` | 派发到对应引擎的工厂(`--engine workflow/agent`) | `evolve_server/__main__.py` |

### A. EvolveEngineMixin(`engines/common.py`)

```python
class EvolveEngineMixin:

        """根据 config 构造 LocalObjectStore / OSSObjectStore / S3ObjectStore / MockBucket"""

            secret_access_key=config.storage_secret_access_key,
            region=config.storage_region,
            session_token=config.storage_session_token,
            local_root=config.local_root,
        )

    def _load_remote_skills(self) -> dict:
        """读 manifest → {name: {version, sha256, ...}}"""
        return load_manifest(self._bucket, self._prefix)

    def _fetch_skill(self, name) -> Optional[str]:
        """读 SKILL.md 文本(对 Nacos 后端,走 NacosSkillClient)"""
        ...

    def _call_storage(self, sync_fn, *args, **kwargs):
        """把同步的 storage 函数包成 awaitable"""
        loop = asyncio.get_running_loop()
        return loop.run_in_executor(None, sync_fn, *args, **kwargs)
```

`_call_storage` 是关键:boto3 / oss2 / Nacos client 都是**同步** SDK,evolve server 在 asyncio 循环里调它们时,要把它们扔到 `run_in_executor`(线程池)里跑,避免阻塞事件循环。

### D. `OpenClawRunner`(`engines/openclaw_runner.py`)

```python
class OpenClawRunner:
    def __init__(self, bin_path, config, transport=None):
        self.bin_path = bin_path
        self.config = config
        self._transport = transport    # for tests(inject mock subprocess)

    async def run(self, *, task, workspace, agents_md_path, timeout, env_overrides=None):
        cmd = [self.bin_path, "--workspace", str(workspace), 
               "--agents-md", str(agents_md_path), "task", task]
        env = os.environ.copy()
        env["OPENCLAW_HOME"] = str(self.config.openclaw_home)
        env.update(self._build_agent_env())
        env.update(env_overrides or {})
        
        proc = await asyncio.create_subprocess_exec(
            *cmd,
            stdout=asyncio.subprocess.PIPE,
            stderr=asyncio.subprocess.PIPE,
            env=env,
        )
        try:
            stdout, stderr = await asyncio.wait_for(proc.communicate(), timeout=timeout)
        except asyncio.TimeoutError:
            proc.kill()
            await proc.wait()
            raise
        if proc.returncode != 0:
            raise RuntimeError(f"openclaw failed: {stderr.decode()[:500]}")
        return parse_output(stdout)

    def _build_agent_env(self):
        return {
            "AGENT_EVOLVE_LLM_API_KEY": self.config.llm_api_key,
            "AGENT_EVOLVE_LLM_BASE_URL": self.config.llm_base_url,
            "AGENT_EVOLVE_MODEL": self.config.llm_model,
        }
```

`_transport` 是 httpx transport 的"注入口",测试时可以替换。

### G. HTTP app(`create_http_app`)

```python
def create_http_app(self):
    from fastapi import FastAPI
    app = FastAPI(title="SkillClaw Evolve Server")
    
    @app.get("/health")
    async def health():
        return {"ok": True, "engine": self.config.engine}
    
    @app.get("/status")
    async def status():
        return self.status_snapshot()
    
    @app.post("/trigger")
    async def trigger():
        return await self.run_once()
    
    return app
```

`/trigger` 是 client 主动触发的入口;`/status` 是 dashboard / 健康检查用。

### H. 周期循环(`run_periodic`)

```python
async def run_periodic(self):
    self._running = True
    while self._running:
        try:
            await self.run_once()
        except Exception as e:
            logger.exception("run_once failed: %s", e)
        await asyncio.sleep(self.config.interval_seconds)
```

`interval_seconds` 默认 600(10 分钟)。`stop()` 设 `_running=False` 退出。

## 常见误区

1. **"`EvolveServer` 和 `AgentEvolveServer` 是兄弟类"** —— **是**。两者都继承 `EvolveEngineMixin`,独立实现 `run_once`。
2. **"两个引擎可以同时跑"** —— **可以**(不同 group_id / 不同 bucket),但**不推荐**——它们会互相覆盖对方的 manifest。
3. **"agent 引擎可以跑任何 LLM"** —— 实际只对 Anthropic Messages / OpenAI Completions 做了稳定适配,其他可能需要 patch `_AnthropicMessagesLLMClient`。
4. **"OpenClaw 是 SkillClaw 自家产品"** —— **不是**。OpenClaw 是 NousResearch 维护的 agent 框架,SkillClaw 通过 `OpenClawRunner` 调它的 CLI 子进程。
5. **"agent 引擎的 workspace 必须有 OpenClaw 装好"** —— **是**。`openclaw_bin` 默认 `"openclaw"`,需要 `npm install -g openclaw`。
6. **"`run_once` 是幂等的"** —— **部分**。同 session 跑两次:第一次会 create skill,第二次会因为 session 已被 `_processed_log` 记录而跳过(如果有 `_processed_log`)。如果 `_processed_log` 重置,可以重复。
7. **"`run_periodic` 的 interval_seconds 改了就生效"** —— 改 config 后需要重启服务。
